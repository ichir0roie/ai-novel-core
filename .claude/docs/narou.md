# 小説家になろうへの投稿(手元だけ)

話の本文を、Playwright(`tool/narou.py`)で小説家になろうへ投稿する。仮実装で、なろうの画面の URL・入力欄・ボタンはまだ実際の画面と突き合わせていない(`tool/narou.py` の頭の定数)。

## いつ動かすか

- 手元(`CLAUDE_CODE_REMOTE` が `true` でない)だけで動かす。web のセッションでは動かさない(`tool.narou` も止まる)。web で頼まれたら、手元のセッションで頼み直してもらう
- スキル `episode` の本文の確定・スキル `revise-episode` の推敲の確定のあと、ユーザに投稿を頼まれたときだけ動かす。頼まれずに投稿しない(スキル `auto-revision` の推敲でも投稿しない)

## ログイン

最初に一度だけ、ユーザが手でログインする。Claude は代わりにログインしない(ID・パスワードを受け取らない)。

```
.venv/bin/python -m tool.narou login
```

- ブラウザが開くので、ユーザがなろうにログインする。ログインの画面を離れたら、クッキーを `.cache/narou/storage_state.json` に残して閉じる(10 分で諦める)
- 以後の投稿はこのクッキーを使う。ログインが切れていたら `post` が止まるので、ユーザに `login` をやり直してもらう
- `.cache/narou/` はリポジトリに入れない(`.gitignore` の `.cache/`)。中身を返答に貼らない
- 初めての手元では、先に `.venv/bin/python -m playwright install chromium` でブラウザを入れる

## 投稿する

`--novel` は、なろうの小説管理の画面の URL に出る小説の番号(Nコードではない)。作品との対応はまだ db に持たないので、ユーザに聞く。

1. 確認画面まで進める(投稿しない):

   ```
   .venv/bin/python -m tool.narou post --episode <話id> --novel <小説の番号>
   ```

   次話投稿の画面にサブタイトル(`episode.title`)と本文(`episode.main_text`)を入れて確認画面まで進み、スクショを `.cache/narou/episode-<話id>-confirm.png` に撮って止まる
2. スクショを Read で見て、サブタイトル・本文の頭と終わりが入っているかを確かめ、ユーザに示して投稿してよいか聞く
3. 認められたら `--submit` を付けて回し直す。確認画面から投稿まで押す

- 画面が開かない・入力欄が見つからないで落ちたら、`--headed` で開いて画面を確かめ、`tool/narou.py` の定数を直す(仮実装の突き合わせ)
- 推敲した話の、すでに投稿した部分を書き換えることはまだできない(新しい部分として足すだけ)
