- `CLAUDE.md` のルールに従う
- 本文は生成関数(`ReviseEpisode` の `claude -p`)に任せず、材料を読んだこのセッションの Claude が直す
- 下の流れは目安。どこをどれだけ直すか・材料を足すか引くか・登場人物や場所を直すかは、指示の意図に合わせて決めてよい
- 大筋(誰が何をしてどうなるか)を変えたくなったときだけユーザに尋ねる。変えると決まったら、スキル `episode` の書き方で書き直す
- 番号だけで頼まれて直す指示が無いときは、その話の行を読んで要点を返す。直す指示をユーザの言葉で受けてから始める(選択肢で問わない)
- GUI の「AI で推敲する」ボタン(待ち行列からスキル `run-ai-tasks` で回る)は、これまでどおり生成関数 `ReviseEpisode` を使う

## 回し方(場所で分ける)

入口の呼び方(スキル `episode` と同じ)と、id・話の引き方は場所で違う。環境変数 `CLAUDE_CODE_REMOTE` を見て、当たる行のファイルだけを Read する。

| `CLAUDE_CODE_REMOTE` | 読むファイル |
| --- | --- |
| `true` でない(手元) | `.claude/skills/episode/local.md` と `.claude/skills/revise-episode/local.md` |
| `true`(web のセッション) | `.claude/skills/episode/web.md` と `.claude/skills/revise-episode/web.md` |

## 流れ

1. **材料を読む**: `ReadEpisodeBrief(episode_id)`。「この話」に今の題・今の本文・プロット・同期の値が入る。長いので、出力をスクラッチパッドのファイルへ書き出して Read する
2. **直し方を決める**: 指示の箇所を字面どおりに直すだけでなく、指示の意図と材料から総合的に判断し、場面の組み立て・順序・会話・描写の配分まで大幅に書き直してよい。大筋は今の本文から保つ
3. **登場人物・場所を見直す(変わるときだけ)**: 台詞・行動のある人物や主な舞台が変わるなら、書く前にスキル `episode` の 2・4(`ReadEpisodeCasting` → 関わった話を読む → 足りない人物・場所を作る → `CastEpisode`)で結び直す。**1 の材料を読み直してから**書く(足した人物の直近の出来事・関係、場所の出来事が材料に入る)
4. **本文を書き直す**: スキル `episode` の「書くとき」に従う。前の話に出ていない人物は初登場として外見・性格を描く。書き直した本文はスクラッチパッドのファイルに置く
5. **確定する**: `CommitEpisode(EpisodeCommitForm(id=…, main_text=<ファイルの中身>, plot_text=…, synced=<材料の「同期」の値>, …))`
   - `synced` は材料の「同期」の値をそのまま渡す(推敲では変えない。渡さないと false になる)
   - `plot_text` は今のプロットの末尾の「## 推敲」の節に、直す指示を `- <指示>` の箇条書きで一行足したもの。節が無ければ空行を挟んで `## 推敲` の見出しから足す。二回目以降は見出しを重ねない
   - `title` は題を直したときだけ渡す。登場人物・場所・視点は 3 の `CastEpisode` で結んであるので渡さない
   - 確定すると、改行が整い、名前だけ出る人物が拾い直され、概要・ミームが作り直される
6. **設定を結ぶ(要るとき)**: 新しく踏まえた設定があれば、スキル `episode` の 5・9 のとおり引いて結ぶ

## 報告する

終わったら書き直した話を読み(読み方はスキル `episode` の回し方のファイル)、直した箇所・字数の変わり方・直した登場人物・場所を短く報告する。
本文・プロット・材料のような長いものは返答に貼らない。
