---
name: character-scenes
description: 人物ごとの出来事を、二人の人物役(character-chat)に一言ずつ会話させて作り、セリフと流れをそのまま出来事の本文に残す(会話モード)。話の当日に居合わせない人物たちがそれぞれどこで誰と何を話したかを描く「当日」と、話と話のあいだの空いた期間を人物ごとの場面で埋める「すきま」の二つの型と、作った出来事を直す「推敲」がある。このセッションの Claude は中継と語り部だけを務め、人物のセリフを書かない。「day ep191」「day 11593/01/05」「gap ep191 ep192」「gap 11593/01/06〜11593/01/14」、作った出来事を指示に沿って直す「ev45 ガレナがニーナのことを聞き返す流れにして」、「その日のほかの人物の出来事を作って」「話のあいだを人物の出来事で埋めて」「二人に会話させて出来事にして」などの依頼で使う。話の本文を書くのはスキル `episode`、人物一人とユーザが話すのはスキル `call-character`。
---

読み方・書き方は手元が `.claude/docs/db.md`、web のセッションが `.claude/docs/web-db.md`。

| 合図 | 型 |
| --- | --- |
| 「day ep<話id>」・「day <年/月/日>」 | 当日: その話(か日)に、話の外にいる人物たちが、どこで誰と何を話したか |
| 「gap ep<話id> ep<話id>」・「gap <年/月/日>〜<年/月/日>」 | すきま: 二つの話のあいだ(か期間)を、人物ごとの場面で埋める |
| 「ev<出来事id> <直す指示>」 | 推敲: このスキルで作った出来事(か、セリフで書いた出来事)を、指示に沿って直す。下の「8. 推敲する」 |

- 人物のセリフ・仕草を決めるのは人物役(`character-chat`)。このセッションの Claude は、片方の返事をもう片方へ渡す中継と、場面を動かす `[場面: …]` だけを書く。セリフを書き足さない・書き換えない。場面の一言目も、人物役に `[場面: …]` を渡して言わせる
- db に書くのは出来事(`CommitEvent`)だけ。プロット・話・人物・関係・来歴は直さない(直す案は報告に書く。来歴はユーザが認めた行だけ足す。下の「6. 出来事を書く」)
- 人物役は一人で十万トークンほど使う。一度に起こすのは四組(八人)までにする

## 1. 範囲を読む

1. **時と章**: 話を名指しされたら、その話の `start`・`story_id`・`character_ids`・`mentioned_character_ids`(表の API の一件)と、本文があれば本文を読む。章(`story`)の `text`・`instruction` と、親の作品の `text` を読む(章ごとの約束に従う。たとえばサンドボックスの章なら、人物を筋のために動かさない)
2. **前後の話**: 範囲の前の話(本文のある一番近いもの)の本文と、範囲から後の同じ章の話のプロット(`ReadEpisodeTexts` の `plot_text`)を読む。後の話のプロットは、場面が先取りしてはいけないこと・食い違ってはいけないことの一覧として使う
3. **今ある出来事**: 範囲の時刻の出来事(`ReadEvents(time=…)` か、表の API の `event` を `time` で並べて絞る)。同じ人物・同じ日の出来事が既にあれば、重ねずにその続きか別の人物にする
4. **人物**: 出す候補の人物ごとに `ReadCharacter` の本文・来歴(範囲の時刻までの行)と、`character_relation` の行(相手を探す)を読む。長いのでスクラッチパッドに書き出して Read で読む

## 2. 組を立てて見せる

人物ごとに一行ずつ、場面の組を立てる。

| 欄 | 決め方 |
| --- | --- |
| 人物 | 当日: 話の登場人物・名前だけ出る人物・その日に同じ町にいるはずの仲間のうち、話の中にいない時間がある人物。すきま: 範囲のあいだに出る話の無い人物 |
| 相手 | 関係の行のある人物から、その人物が帰る先・会いに行く先・避けられない相手を選ぶ。家族・家主・師・幼なじみなど、まだ場面で向き合っていない相手を先にする |
| 時刻・場所 | 人の動きとして自然な時刻(旅から帰るなら昼に着いて夕方に家、など)。場所は `location` の行から一番近いものを選び、無ければ親の場所にして報告に書く |
| 狙い | その人物の芯・欲しいもの・怖いもの・抱えている借りや約束のうち、この場面で動くもの |
| 触れない | 後の話のプロットが決めていること(誰と初めて会う、何を初めて知る)で、この場面で先に起こしてはいけないもの |

- 組の表をユーザに見せ、認めを受けてから人物役を起こす(人物役は高くつく)。相手が二つ以上考えられる・後の話のプロットと時期がずれる組は、`AskUserQuestion` で選んでもらう
- すきまは、人物ごとに一場面か二場面を、範囲の中に日をばらして置く。同じ人物の場面は時刻の順に回し、前の場面の出来事を確定してから次の場面の人物役を起こす(人物役は、居合わせた出来事を `knowledge` の「居合わせた出来事」で、自分の知ることとして読む)

## 3. 人物役を起こす

組ごとに `character-chat` を二人起こす(並べて起こしてよい)。最初のメッセージは次の形にする。暦の時刻は `時刻:` の行にだけ書き、ほかの欄には書かない。

```
時刻: <年/月/日 時:分:秒>
人物: <人物id>
いまの自分:
<その時刻までにその人物が見た・聞いた・したことのうち、この場面に要るものを、その人物の目から数行。いまどこにいて、何をしに来たか>
話し相手: <人物名(人物id)。続き柄・間柄>
場面: <時刻の様子・場所・相手がどう現れるか。「一度の返事は短めにして、自分の番だけで止める」「旅のことは、聞かれたら一度に一つの出来事くらいまで話す」のような長さの指示>
```

- 「いまの自分」に、その人物が知らないこと(ほかの人物の内心・居合わせなかった場面・後のプロット)を書かない
- 言葉を話さない第三の人物がその場にいるときは、主に話す側の人物役の `場面:` に、その人物の仕草を見えたこととして短く書いてよいと添える

## 4. 中継する

1. **口開け**: 先に話す側へ `[場面: <いまの様子>。まず自分から口を開く]` だけを送る
2. **渡す**: 返事が来たら、相手の人物役へそのまま渡す。変えてよいのは次だけ
   - 渡す先の人物を指す語(名前・「母さま」など)を「あなた」に替える
   - 渡す先の人物が知らない名(人の名・道具の名)を、見て分かる言い方に替える(「レトヴァ」→「ドワーフの女」、剣の銘 →「背の剣」)
   - 時が飛ぶ・場所が移るときは、頭に `[場面: …]` を足す(「湯を使って着替え、居間で向かい合って座る」)
3. **進み**: 長い待ちが続くときは、ユーザに何組目の何往復目かだけを一行で知らせる
4. **締め**: 五〜八往復で、締めたい側へ渡すメッセージの末尾に `[場面: この返事で締める。<添えてよいこと>]` を足す。返事の最後の行が `[退場]` なら、その組は終わり。相手へは送らない
5. **やり直し**: ユーザが流れを変えたいと言ったら、両方の人物役へ `[場面: やり直し。<誰>が「<セリフ>」と言った所まで戻る。そのあとの<出来事>は起きなかったことにする。<新しい方向>]` を送り、戻した所から中継し直す

## 5. 確かめる

組ごとに、セリフと仕草を、本文・プロット・来歴・関係と照らす。

- 食い違いは三つに分けて扱う
  - **言い方の違い**: 前の話の本文と言い回しは違うが、伝えたいことを捉えているセリフ。直さない
  - **小さな事実の取り違え**: 部屋の数・どの晩だったか・物の名など。出来事の本文で直し、直した所を報告に書く
  - **筋との食い違い**: 後の話のプロットと合わない約束・知ったこと・時期(「明日一緒に行く」が後の話の初対面とぶつかる、など)。直さずに報告に書き、ユーザに決めてもらう
- 人物役が地名・方角・人数などを言い切っていて、db で確かめられないものは、出来事の本文に書かずに報告に書く

## 6. 出来事を書く

書く前に `ReadWritingStyle` で出来事の範囲の行を読む。本文は組ごとに次の形で書く。

```
<一段落: 誰が・いつ頃・どこで・誰と向き合ったか。二人の人物役に一言ずつ会話させた記録で、セリフは話の本文の下敷きにする、と添える>

# <場面の見出し>

<地の文は、誰が何をしたかを短く。仕草は人物役の返事から、話の運びに要るものだけ>
<人物名>:「<セリフ>」「<セリフ>」

# 話に出なかったこと

<どちらも話題にしなかった事柄(後の場面の前提になるもの)。事柄だけを書き、なぜ言わなかったか・胸の内は書かない>
```

- 本文は居合わせた人物みなが自分の覚えとして読む(人物役の `knowledge` の「居合わせた出来事」)。その場で見えたこと・聞こえたことの客観的な事実だけを書く。人物の内心・狙い・口にしなかった本音・表情から推し量った気持ちは書かない(「〜を気にしているようだった」も書かない。仕草はそのまま書く)
- セリフは人物役の返事のとおりに写す。省いてよいのは、同じことを二度言ったものだけ
- 後の場面に効く、一人だけが抱えたこと(人物役が仕草とセリフで隠し通したこと)は、出来事に書かず、報告の「来歴に残すとよさそうなこと」に挙げる。ユーザが認めたら、その人物の来歴に、出来事の時刻を `start`、知る相手を本人だけにした行(種別「記憶」「隠し事」など)で足す
- 書き終えたら、スクラッチパッドの `character-scenes/<組>.txt` に置き、`CommitEvent` を `flows.run` で回す(web は `run_in_background`)。いくつかの組は一つの python の実行で順に確定してよい

```
{'event': {'name': '<題>: <人物>と<相手>', 'time': '<年/月/日 時:分:秒>', 'location_id': <場所id>, 'character_ids': [<話した二人と、居合わせた人物>], 'text': Path('<scratchpad>/character-scenes/<組>.txt').read_text(encoding='utf-8')}}
```

- 題は、当日なら話の題、すきまなら範囲の短い呼び名(「帰郷のあと」など)
- 直すときは `UpdateEvent`(`{'event': {'id': …, 'text': …}}`)で本文をまるごと渡す

## 7. 報告する

- 確定した出来事の表(id・題・時刻・場所)
- 組ごとに、流れを三〜五行と、話の本文に使えそうなセリフを二〜四つ
- 5 の「小さな事実の取り違え」で直した所と、「筋との食い違い」の一覧(どの話のプロットとぶつかるか)
- このセッションの Claude が決めた所(組の相手・時刻・場所・場面の一言)
- 人物・関係の来歴に残すとよさそうなこと(約束・頼みごと・知ったこと)。書くのはユーザに頼まれてから

## 8. 推敲する

「ev<出来事id> <直す指示>」で、出来事を直す。1・2 は読むだけにし、組の表は見せない。

1. **読む**: 出来事の一件(表の API の `event/<id>` の `.record`。`text`・`time`・`location_id`・`character_ids`)と、1 の範囲の材料(前の話の本文・後の話のプロット・人物)を、出来事の時刻で読む
2. **直し方を分ける**
   - **文の直し**: 事実の取り違え・地の文の言い回し・場面の見出し・「話に出なかったこと」の直し・内心の言い回しを客観的な事実に直す・セリフを削る。人物役を起こさずに、本文を直接直す。セリフを書き足す・言い換える直しは、ここに入れない
   - **流れの直し**: 話の向き・話題・締め方を変える、セリフを足す・言い換える。人物役を起こし直して、分かれ目から先を演じ直す
3. **演じ直す**(流れの直しだけ): 分かれ目(直す指示に当たる、一番前のセリフ)を決める
   - 二人の `character-chat` を 3 の形で起こし、`場面:` の前に次の欄を足す。分かれ目より前のやり取りを、出来事の本文から写す(相手の名は 4 の決まりで替える)
   - `時刻:` は出来事の時刻の 1 分前にする。人物役の `knowledge` には居合わせた出来事が本文で入るので、出来事の時刻のままだと、直す出来事の分かれ目より後まで読んでしまう

     ```
     この場面で、ここまでに起きたこと:
     <分かれ目より前の、自分と相手のセリフと仕草>
     ```

   - 分かれ目の直前に話した側の相手へ、`[場面: <直す指示を、その場の成り行きとして言い換えたもの>]` を渡して、4 の中継を始める
   - 起こし直す前に、同じセッションで同じ組の人物役が残っていれば、起こし直さずに 4 の「やり直し」で戻してよい
4. **書く**: 分かれ目より前は元の本文のまま、後ろを演じ直した分に替える。5 で確かめ、6 の形で書く。書く前に `ReadWritingStyle` で出来事の範囲の行を読む
5. **直す**: `UpdateEvent` を `flows.run` で回す(web は `run_in_background`)。本文はまるごと渡す

   ```
   {'event': {'id': <出来事id>, 'text': Path('<scratchpad>/character-scenes/ev<出来事id>.txt').read_text(encoding='utf-8')}}
   ```

   - 居合わせた人物が変わったときだけ `character_ids` を渡す(渡すと当事者をまるごと置き換えるので、残す人物も全員並べる)。時刻・場所を変えたときは `time`・`location_id` も渡す
   - `UpdateEvent` は要約だけを作り直し、出来事の種は抜き出し直さない。演じ直しで新しい出来事(約束・知ったこと・事件)が足されたときだけ、`event_seed.extract_event_seeds.ExtractEventSeeds` `{'rows': [{'table': 'event', 'id': <出来事id>}]}` を `flows.run` で回す(前の本文から抜いた種は残る。消えた筋の種があれば報告に書く)
6. **報告する**: 直し方(文の直し・流れの直し)と分かれ目、変わったやり取りの前後(元のセリフ → 新しいセリフを二〜四つ)、5 の確かめで出た食い違い、種を抜き出し直したか
