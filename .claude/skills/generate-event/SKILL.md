「event」(「イベント生成」も同じ)が始める合図。後ろに人物・相手・方向づけ・時刻が付けば、それに従う。
`ev<出来事id>` が付けば、作者が置いた親の出来事の中で起こす(下の「親の出来事を指定する」)。`ev<出来事id> write` なら、親に書いた段取りから Claude が場面ごとに書く(下の「作者の段取りから書く」)。

- db の読み書きは自分の場所の決まり(手元は `.claude/docs/db.md`、web のセッションは `.claude/docs/web-db.md`)で行う
- コードは変えない。作品の中身はリポジトリに置かない
- 一件ごとに確定してから次の単位へ進む(後の人物は、前の単位で足した出来事を自分の知ることとして読む)

## 基本の単位

人物一人の、一回の出来事の生成。次の順で決めて、出来事を一件足す。

1. **人物**: 下の「対象の人物」で決めた一人
2. **時刻**: 指示に日付・時刻が無ければ渡さない。入口が、その人物が本文のある話で最後に出た時刻(その後に AI が足した出来事があればそれ)の翌日以降で、気力の戻る時刻に決める(`.docs/world-expansion.md` の「人物モード」の 2)。日付を言われたら、その時刻を渡す
   - 渡す時刻は、人物の行の暦(無ければ作品の暦)の表記で書く。SQL で読んだ列の生の値(`118250421053730`)や、それを読み下した西暦の表記(`11825/04/21`)を渡さない。暦が西暦でない作品では、桁が別の時刻として読まれ、遠い先に出来事が入る
   - 「最新話の次の日」のように話から決めるときは、話の時刻を入口(`ReadEpisodeTexts` の `start`・`end`。入口がその話の暦で書き出す)で読み、その表記の日付を一つ進める
3. **道**: 下の「道を選ぶ」で一つ選ぶ
4. **足す**: 選んだ道の入口・スキルで、出来事を一件足す
5. **返す**: `<人物> <時刻>: <狙い・場面>(相手: <相手>) → 出来事 <id>「<名前>」(<成り行き>)` を一行で返す。道ごとの詳しい報告は、その道のスキルの報告に従う

## 対象の人物

| 指示 | 対象 | 回す順 |
| --- | --- | --- |
| 人物の名指し無し(「event」) | 本文のある最新の話の登場人物(名前だけ出る人物は除く)から一人。入口(`ActCharacter` の `character_id` を省く)に、行動力の重みで引かせる | 一回 |
| 人物の名指し(「event ノア」) | その人物 | 一回 |
| 人物と周り(「event ノアとその周辺」「ノアの周りの人たち」) | その人物と、その人物が登場した最新の本文のある話の登場人物(名前だけ出る人物は除く) | 名指しの人物を先に、残りを id の順に一人一回ずつ |
| 何人か・何回か(「event ノア ミレア」「event 3」) | 名指しの人物を順に。回数だけなら、名指し無しの単位をその回数 | 言われた順 |

- 最新の話は、本文のある話のうち、時刻(終わりがあれば終わり)が一番遅いもの(`expansion_query.latest_written_episode`)。手元は SQL で選んでよい(`select id, title from episode where main_text <> '' and start is not null order by coalesce("end", start) desc limit 1`。時刻はここで読まず、上の「時刻」のとおり入口で読む)。web のセッションは表の API の `episode` の一覧の `letters` と `start`・`end` で選ぶ。登場人物は表の API の `episode` の一件の `character_ids`
- 人物の名前から id を引くのは `.claude/docs/db.md` の「行を引く」
- 生きていない・居場所が分からない・行動力が無で動けない人物は、入口が `failed` で返す。飛ばして次の人物へ進み、わけを報告に書く

## 親の出来事を指定する

「event ev<親の出来事id> [<日時>] <人物名> [<人物名>…] [<方向づけ>]」は、作者が置いた親の出来事の中の一場面を、人物モードで一件起こす。

- 一人目の人物が動く人物、二人目からは居合わせる人物(住まいを問わず目の前にいて、巻きこめる相手になる)。人物の名指しが無ければ、親とその子の出来事の当事者を挙げて、作者に誰を動かすかを尋ねる
- 日時が無ければ渡さない。入口が、人物が最後に出た時刻から日を空けた時刻を親の始まりより後に寄せる。親の期間(`time`〜`end`)の外になれば `failed` で返るので、わけを報告して作者に日時を尋ねる
- 呼び方: `expansion.act_character.ActCharacter` `{'character_id': <一人目>, 'partner_ids': [<二人目から>], 'parent_event_id': <親>, 'time': <日時。無ければ省く>, 'nudge': <方向づけ。無ければ省く>, 'act_count': 1}`
- 語り部が、親とその上の出来事の本文と、親の子のうち一手の前後に置かれた出来事をもとに、人物の目の前の状況を整える。人物には親の本文を渡さない。足した出来事は親の子になる(企てには結ばない)
- 親は作者の行のまま。直さない
- 返す一行に、親を添える: `<人物> <時刻>: <狙い・場面>(相手: <相手>) → 出来事 <id>「<名前>」(<成り行き>。親: ev<親id>「<親の名前>」)`

## 作者の段取りから書く

「event ev<親の出来事id> write」は、作者が親の出来事に書いた段取り(会話で決めた場面・起きること)をもとに、このセッションの Claude が場面ごとに子の出来事を書く。人物モードのサイコロ(成り行き)は使わない。人物モードでは、成り行きしだいで段取りの山(等級が上がる・獣を討つなど)が起きずに終わるので、段取りどおりに起こしたい親はこの道で書く。

1. 親とその上の出来事の本文、親の子として既にある出来事、場面に出る人物の住まいを読む。段取りに書いてある場面を、時刻の順に一件ずつ子の出来事にする。段取りに書いてあることは変えずに起こす
2. 段取りで決まらない所(その人物の言い回し・反応・決め方)だけ、人物役(`character-chat`)をその場面の時刻で呼んで聞く。最初のメッセージに、時刻・人物の id・「いまの自分」(その場面までに自分の身に起きたこと。段取りのうち、その人物が知っていることだけ)・話し相手を渡し、「支度ができた」が返ったら、相手の言葉か仕草を一つ送って返事を受ける。呼ぶのは要る人物だけで、場面ごとに一人か二人にする。段取りで足りる場面では呼ばない
3. 本文は出来事の書き方(範囲「出来事」)で、客観的な事実だけを書く。人物役の返事のセリフはそのまま写してよい。場所は場面の場所(人物の住まいでなく)、終わりは場面の終わりの時刻にする
4. 書いた本文を作者に見せ、確かめを受けてから `event.commit_event.CommitEvent` で親の子として足す(`parent_event_id`・`time`・`end`・`location_id`・`character_ids` に居合わせた人物)。親は作者の行のまま直さない
5. 返す一行: `<時刻> <場面> → 出来事 <id>「<名前>」(呼んだ人物役: <人物>。親: ev<親id>「<親の名前>」)`

## 道を選ぶ

| 指示 | 道 | 呼び方 |
| --- | --- | --- |
| 人物だけ・方向づけ(「港の疫病を気にかけて」)・何も無し | 人物モード。人物が自分の知ること・モチベーションから一手を打ち、巻きこみたい相手とは言葉を交わす。安い | `expansion.act_character.ActCharacter` `{'character_id': <人物>, 'nudge': <方向づけ。無ければ省く>, 'act_count': 1}`。時刻を言われたら `time`。入口の返り・取り消しはスキル `auto-act` の「入口」 |
| 相手を名指しして話させる・会話やセリフを残したい(「ミレアと話す」「〇〇と言い合う」) | 会話モード。二人の人物役(`character-chat`)に一言ずつ会話させ、セリフを出来事の本文に残す。人物役一人で十万トークンほど使う | スキル `character-scenes` の「2」〜「7」を、この人物と相手の一組だけで回す(組の表は一行。範囲は上の時刻) |
| 場面の中身を決めている(「市場で喧嘩」「夜に盗みが入る」) | 場面の指定。名前を場面の指定に、時刻・場所・当事者を決めて出来事を一件起こす | `event.generate_event.GenerateEvent` `{'event': {'name': <場面>, 'time': <時刻>, 'character_ids': [<人物>, …], 'location_id': <省けば当事者の現在地>}}`。時刻を言われていなければ、`ActCharacter` と同じく最後に出た時刻の翌日以降で決め、決めた時刻を報告に書く |

- どれにも当たらない・二つに当たるときは、人物モードにする
- 人物モードと場面の指定は、AI が出来事の本文を書く(書き手は入口が立てる)。会話モードは、このセッションの Claude が人物役のセリフを写して書く(書き方はスキル `character-scenes` の「6」)
- 人物モードの書き込みは `ActCharacter` だけで行い、このスキルから別の入口で行を直さない

## 終える

回した単位を、上の「返す」の一行ずつ並べ、次を添える。

- 失敗した単位とそのわけ
- 人物モードで足した手を取り消すなら「展開 <id> を取り消して」(`RevertExpansion`)、会話モード・場面の指定で足した出来事を直すなら「ev<出来事id> <直す指示>」(スキル `character-scenes` の「8」)
- 続けて回すなら「auto」(スキル `auto-act`)
