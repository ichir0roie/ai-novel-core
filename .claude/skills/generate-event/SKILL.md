「event」(「イベント生成」も同じ)が始める合図。後ろに日付・人物・相手・方向づけが付けば、それに従う。
`ev<出来事id>` が付けば、作者が置いた親の出来事の中で起こす(下の「親の出来事を指定する」)。`ev<出来事id> write` なら、親に書いた段取りから Claude が場面ごとに書く(下の「作者の段取りから書く」)。

- db の読み書きは自分の場所の決まり(手元は `.claude/docs/db.md`、web のセッションは `.claude/docs/web-db.md`)で行う
- コードは変えない。作品の中身はリポジトリに置かない
- 一回ごとに確定してから次へ進む(後の日の人物は、前の日に足した出来事を自分の知ることとして読む)

## 基本の単位

人物たちの一日。次の順で決めて、入口 `expansion.simulate_day.SimulateDay`(claude を叩く入口)を一回呼ぶ。

1. **人物**: 下の「対象の人物」で決めた人物たち(`constants.DAY_CHARACTER_LIMIT` 人まで)
2. **日**: 指示に日付が無ければ渡さない。入口が、人物が最後に出た日(本文のある話と、その後に AI が足した出来事)の翌日にする。日付を言われたら、その日を渡す
   - 渡す日付の形は `.claude/docs/db.md` の「時刻を読む・写す」(人物の暦の日付。時刻は付けない)
   - 「最新話の次の日」のように話から決めるときは、話の時刻を入口(`ReadEpisodeTexts` の `start`・`end`。入口がその話の暦で書き出す)で読み、その表記の日付を一つ進める
3. **道**: 下の「道を選ぶ」で一つ選ぶ
4. **動かす**: 選んだ道の入口・スキルで、その日を動かす
5. **返す**: 動かした日を頭に、人物ごとに一行ずつ返す(`<人物> <日付>: 出来事 <id>「<名前>」(居合わせた相手: <相手>。行動 <数> 件)`)。道ごとの詳しい報告は、その道のスキルの報告に従う

- 呼び方: `{'character_ids': [<人物>, …], 'date': <日付。無ければ省く>, 'nudge': <方向づけ。無ければ省く>}`。人物を名指ししないときは `character_ids` を省く
- 入口の中身(一時間ごとの動かし方・予定・眠気と空腹・居合わせた人物どうしの応じ・一日の記録)と返りの読み方は、スキル `auto-act` の「入口」
- 動かせるのは、詳細の場所(詳細マップの場所)にいる人物だけ。その日のあいだは、人物のいるエリア(都市など)の詳細の場所のあいだを動く。詳細の場所にいない人物・その日をもう動かした人物は `failed` に返る。わけを報告に書き、居場所を直すかは作者に任せる
- 一日で人物の目を何十回も呼ぶので、数十分かかることがある。web では `flows.run` を `run_in_background` で回す

## 対象の人物

| 指示 | 対象 |
| --- | --- |
| 人物の名指し無し(「event」) | 本文のある最新の話の登場人物(名前だけ出る人物は除く)。`character_ids` を省いて入口に選ばせる |
| 人物の名指し(「event ノア」「event ノア ミレア」) | その人物たち |
| 人物と周り(「event ノアとその周辺」「ノアの周りの人たち」) | その人物と、その人物が登場した最新の本文のある話の登場人物(名前だけ出る人物は除く) |
| 何日か(「event 3」「event ノア 3日」) | 対象の人物で、その日数だけ日を一日ずつ進めて回す(二日目からは前の日の翌日を `date` に渡す) |

- 最新の話は、本文のある話のうち、時刻(終わりがあれば終わり)が一番遅いもの(`expansion_query.latest_written_episode`)。手元は SQL で選んでよい(`select id, title from episode where main_text <> '' and start is not null order by coalesce("end", start) desc limit 1`。時刻はここで読まず、上の「日」のとおり入口で読む)。web のセッションは表の API の `episode` の一覧の `letters` と `start`・`end` で選ぶ。登場人物は表の API の `episode` の一件の `character_ids`
- 人物の名前から id を引くのは `.claude/docs/db.md` の「行を引く」
- 人数が `DAY_CHARACTER_LIMIT` を超えるときは、名指しの人物を先に、残りを id の順に分けて、同じ日を何回かに分けて回す(同じ回にいない人物どうしは、その日に応じ合わない)

## 親の出来事を指定する

「event ev<親の出来事id> [<日付>] <人物名> [<人物名>…] [<方向づけ>]」は、作者が置いた親の出来事の中の一日を動かし、人物ごとの一日の出来事を親の子にする。

- 人物の名指しが無ければ、親とその子の出来事の当事者を挙げて、作者に誰を動かすかを尋ねる
- 日付が無ければ渡さない。入口の決めた日が親の期間(`time`〜`end`)の外になれば、わけを報告して作者に日付を尋ねる(日付は返りの `date`)
- 呼び方: `{'character_ids': [<人物>, …], 'parent_event_id': <親>, 'date': <日付。無ければ省く>, 'nudge': <方向づけ。無ければ省く>}`
- 一日を記録する段が、親とその上の出来事の本文と、親の子のうちその日の前後に置かれた出来事を読み、それと食い違わない記録にする。人物の目には親の本文を渡さない
- 親は作者の行のまま。直さない
- 返す一行に、親を添える: `<人物> <日付>: 出来事 <id>「<名前>」(居合わせた相手: <相手>。親: ev<親id>「<親の名前>」)`

## 作者の段取りから書く

「event ev<親の出来事id> write」は、作者が親の出来事に書いた段取り(会話で決めた場面・起きること)をもとに、このセッションの Claude が場面ごとに子の出来事を書く。人物モードは使わない。人物モードでは、人物がその時間を自分で決めるので段取りの山(等級が上がる・獣を討つなど)が起きずに終わることがあり、段取りどおりに起こしたい親はこの道で書く。

1. 親とその上の出来事の本文、親の子として既にある出来事、場面に出る人物の住まいを読む。段取りに書いてある場面を、時刻の順に一件ずつ子の出来事にする。段取りに書いてあることは変えずに起こす
2. 段取りで決まらない所(その人物の言い回し・反応・決め方)だけ、人物役(`character-chat`)をその場面の時刻で呼んで聞く。最初のメッセージに、時刻・人物の id・「いまの自分」(その場面までに自分の身に起きたこと。段取りのうち、その人物が知っていることだけ)・話し相手を渡し、「支度ができた」が返ったら、相手の言葉か仕草を一つ送って返事を受ける。呼ぶのは要る人物だけで、場面ごとに一人か二人にする。段取りで足りる場面では呼ばない
3. 本文は出来事の書き方(範囲「出来事」)で、客観的な事実だけを書く。人物役の返事のセリフはそのまま写してよい。場所は場面の場所(人物の住まいでなく)、終わりは場面の終わりの時刻にする
4. 書いた本文を作者に見せ、確かめを受けてから `event.commit_event.CommitEvent` で親の子として足す(`parent_event_id`・`time`・`end`・`location_id`・`character_ids` に居合わせた人物)。親は作者の行のまま直さない
5. 返す一行: `<時刻> <場面> → 出来事 <id>「<名前>」(呼んだ人物役: <人物>。親: ev<親id>「<親の名前>」)`

## 道を選ぶ

| 指示 | 道 | 呼び方 |
| --- | --- | --- |
| 人物・日付・方向づけ(「港の疫病を気にかけて」)・何も無し | 人物モード。人物たちの一日を一時間ずつ動かし、居合わせた人物どうしを応じさせる | 上の「基本の単位」 |
| 相手を名指しして話させる・会話やセリフを残したい(「ミレアと話す」「〇〇と言い合う」) | 会話モード。二人の人物役(`character-chat`)に一言ずつ会話させ、セリフを出来事の本文に残す。人物役一人で十万トークンほど使う | スキル `character-scenes` の「2」〜「7」を、この人物と相手の一組だけで回す(組の表は一行。範囲は上の日) |
| 場面の中身を決めている(「市場で喧嘩」「夜に盗みが入る」) | 場面の指定。名前を場面の指定に、時刻・場所・当事者を決めて出来事を一件起こす | `event.generate_event.GenerateEvent` `{'event': {'name': <場面>, 'time': <時刻>, 'character_ids': [<人物>, …], 'location_id': <省けば当事者の現在地>}}`。時刻を言われていなければ、人物が最後に出た日の翌日の昼で決め、決めた時刻を報告に書く |

- どれにも当たらない・二つに当たるときは、人物モードにする
- 人物モードと場面の指定は、AI が出来事の本文を書く(書き手は入口が立てる)。会話モードは、このセッションの Claude が人物役のセリフを写して書く(書き方はスキル `character-scenes` の「6」)
- 人物モードの書き込みは `SimulateDay` だけで行い、このスキルから別の入口で行を直さない

## 終える

回した日を、上の「返す」の形で並べ、次を添える。

- 動かせなかった人物とそのわけ
- 人物モードで足した一日を取り消すなら「展開 <id> を取り消して」(`RevertExpansion`。人物の一日ずつ)、会話モード・場面の指定で足した出来事を直すなら「ev<出来事id> <直す指示>」(スキル `character-scenes` の「8」)
- 日を進めて続けて回すなら「auto」(スキル `auto-act`)
