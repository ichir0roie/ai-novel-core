# 本文を書く

スキル `episode` の手順 8。スキル `interactive-episode`・`complete-episode`・`revise-episode` も、本文の書き方はここに従う。

## 本文に起こす

手順 6 で人物役に手番を回したときだけ。

- 筋はプロットではなく、`read --episode <id>` で読んだセッションの行から取る(演じた場面がプロットからずれていれば、セッションの行に従う)。行は手番の順(id の順)に、語り部の要求(状況)・人物の内心・行動・セリフ・狙いを持つ
- 材料は手順 7 で書き出したファイルを使う(読み直すと要約の確かめが走り直す)
- 視点に沿って小説にする。人物役のセリフは中身(言うこと・言わないこと)をそのまま使い、言い回しは人物の口調と文体の見本のセリフに揃えて直す。描写は地の文で厚くする。視点人物の内心は、その人物の行の内心から地の文に起こす。視点人物以外の内心は、語りが許す範囲でだけ書く
- 何人もが同じ中身を返した所・読者がもう読んだ中身をなぞるセリフ・場面を進めない決まりや指図の並べ立ての扱いは、材料の「書き方」(本文の範囲の「手番の行から本文に起こすとき」)に従う
- 人物の狙いは、その人物の行の内心・狙いから取る。まとめの「狙いの取り違え」に挙げた所は、言った人物の受け取り方として書き、動いた人物の心の声・地の文の事実・後悔・詫びに移さない
- セリフの言い回しに、来歴・場所の説明の書き言葉や慣用句が混ざっていれば、その人物が普段使う言葉に直す

## 書くとき

- 材料の「書き方」(db の全体の行・作品の指示・本文の行・推敲の行・話の指示)と「材料の読み方」(見出しの意味と禁止事項。`ai/instructions/materials.py` の `EPISODE_BRIEF_NOTES`)に従う。ここに書き方を足さない
- 推敲の行は、これまでの推敲で作者に直された所と、その直し方の記録。書く前に読み、書き終えたら確定の前に、その項目を一つずつ本文に当てて見直し、当たる所を直す
- 「秘密」の付いた来歴・履歴は、知らない人物の台詞・内心・視点の地の文には出さず、場面で明かされたときだけ書く
- 登場人物の直近の出来事はこの話の前に済んだこと。「この時点より後に既に決まっている出来事」と矛盾させず、先回りしない
- 前の話に出ていない人物は初登場として、外見・性格を描く
- 人物が何のために動いたかは、材料の「材料の読み方」のとおり、プロットと人物の行から取る。手番を回さずに書くときも、プロットに無い動機と、それへの後悔・詫びを足さない
- 人物の持ち物・武器・身なりは、材料の「装い」と、来歴の種別「持ち物」の行と体格に合わせる。装いが空なら、手順 2 で読んだ関わった話の本文で、最後に手にした・手放した物を確かめてから書く
- 書くうちに登場人物・場所を変えたくなったら、`CastEpisode` で結び直し、手順 7 を読み直してから書き続ける。書くうちに新しい固有の語を使うなら、`ResolveIdeas` で照らして返った `ideas` を踏まえる

## 書き終えたら

1. 本文・プロット・セッションの行に出た固有の語のうち、材料の「設定」に無いものをすべて挙げ、`AddIdeas` でまとめて足す(どの語を足すか・種別は `turns.md` の「新しい語を足す」のとおり)
2. 下の「確定の前に日本語を見直す」をする

## 確定の前に日本語を見直す

本文を書いた・書き直したあと、確定の前に毎回する(ユーザが書いた本文を反映する「ep61 書いた」ではしない)。書き方は百を超える決まりを並べていて、書きながらでは直訳調の文と古めかしい言い回しが抜ける。日本語の自然さだけを見る役に、別に読ませる。

1. 材料の「書き方」を、手順 7 で書き出したファイルから `jq -r '.["書き方"]'` で `<scratchpad>/style-<話id>.txt` に抜く
2. エージェント `japanese-check` を起こし、本文のファイル・書き方のファイル・書き出す先(`<scratchpad>/jcheck-<話id>`)のパスを渡す。直す所の例は渡さない(例を渡すと、例と字面の似た文だけを探す)
3. 返った一覧を一つずつ読む。筋・セリフの中身・人物の口調・視点まで変えた直しは採らない。直した文が前後と同じ語・同じ主語を重ねていたら、言い直す
4. 採った直しの入った本文で確定する

## 登場人物・場所

- 登場人物(`episode_character`)は、この話で台詞・行動のある人物。`ReadEpisodeCasting` の「登場人物」「名前だけ出る人物」「登場人物の候補」から選び、`CastEpisode` の `character_ids` に全員を渡す(まるごと置き換わる)
- 話題・回想・噂に名前が出るだけの人物は入れない(`mentioned=true` の行として自動で拾われる)。群衆・名前の要らない通りすがりも入れない
- db に人物として登録されている人物は名前で書く。登録されていない端役(宿の主・御者・通りすがりなど)は人物として作らず、プロット・語り・本文のどこでも名前を付けずに「隊商の主」「口笛の男」のように役割か見た目で書く(名前を付けると、同じ名の別の人物と取り違えて名前だけ出る人物に拾われる)。名前の要るほど話に関わる人物だけを、下のとおり作る
- 呼び名が違っても(役職・続柄・あだ名など)、人物像から同じ人物と分かれば既存の人物を使う
- db にいない人物が要るなら、作ってから `character_ids` に入れる。作品・場所・時刻に馴染む人物にする
  - `CommitCharacter`: 説明は `text` に書く。来歴の節目は起きた時刻(`'<年/月/日>'`。年だけ決まっていれば年の整数)を `start` にした行にし、サブキャラクターの来歴はこの話の時刻までにする
  - AI に組ませるなら `GenerateCharacter`(プロットを渡すと、その時刻・場所で役どころを果たせる年齢になる)
- 場所: 主な舞台が材料の場所より細かければ、「この場所の中の既知の場所」から選んで `location_id` にする。無ければ `CommitLocation` で足す(`parent_id` は材料の一番細かい場所id)
- 視点(`viewpoint_character_id`)は、頼まれたかプロットで決まっているときだけ入れる
