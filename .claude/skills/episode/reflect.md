# 世界に反映する(確定のあと)

スキル `episode` の手順 10 と、「ep<話id> 書いた」。スキル `interactive-episode`・`complete-episode` も、確定のあとはここに従う。

本文の確定(`CommitEpisode`)は AI を回さない。確定のあと、登場人物ごとの差分を一つの形で入れる(`data_access_logic/readme.md` の「話の差分」)。差分は次の五つで、AI を挟まずに db へ入る。

| 差分 | 入る先 |
| --- | --- |
| `histories`: この話でしたこと・起きたこと・知ったこと(一つの出来事につき一行) | その人物の来歴の行(話の時刻から、本人だけが知る) |
| `met`: この話で初めて言葉を交わした・名乗り合った相手 | 本人から相手への向きの関係(すでにあれば足さない) |
| `worn`: 身に着けた・手にした、人から見て分かる物 | 種別「装い」のスキル |
| `removed`: 外した・手放した・壊れた物(今の装いの名前) | その装いの来歴の行を話の時刻で終える |
| `moved_to`: 住まい・拠点を移した先(場所の名前) | 居場所の行 |

- ほかの人物の秘密を知ったときは、知った人物の `histories` に「誰の何を知ったか」を書く。秘密を持つ人物の行と、関係の来歴には触れない(関係の来歴は両側の人物が読むので、秘密を持つ側に漏れる)
- 当てられない値(装いに無い物・名前で一つに決まらない場所・登場人物でない相手)は入らずに `skipped` に返る。取りこぼしは損失として許し、報告に書くだけにする
- 体つき・傷・口調の変化、隠し持つ物の細かな出入りは差分に無い。要る所は `histories` の一行に書く(作者が後で直す)

## 差分の出どころ

**手番を回した話**(手順 6 で人物役を起こした):

1. ユーザがまとめを認めたら、人物役みなに「話を締める」を送る(`turns.md` の流れの 5)。人物役は、自分の演じた手番から自分の差分を書き(`tool.episode_session close`)、「締めた」と返す
2. 手順 9 で確定したら、全員の「締めた」を受けてから、`.venv/bin/python -m tool.episode_session apply --episode <id>` を打つ。人物役の差分と、手番で言ったセリフ(覚えは言ったとおり)がまとめて入る。返りの `差分の無い人物` に挙がった人物は、まだ締めていないか、変わったことが無い
3. 人物役にはもう番を送らない

**手番を回していない話**(一人だけの話・「ep<話id> 書いた」・「ep<話id> 補完」):

- 確定のあと、`episode.reflect_episode.ReflectEpisode` に `{'episode_id': …}` を渡す(AI が本文から全員の差分を一度で書き、同じように入れて、セリフを本文から拾い直す。数分かかるので、web では `run_in_background`)

どちらも、推敲(スキル `revise-episode`)で本文を直した話には入れ直さない(来歴・関係が重なり、昔の話の居場所に戻る)。

## ユーザが書いた本文を反映する

「ep61 書いた」は、ユーザが自分で書いた本文(GUI の話の画面で保存したもの)を確定し、世界に反映する合図。本文はユーザのもので、このセッションの Claude は書き足さない・直さない(確定のときに改行が整うだけ)。

1. **話を読む**: `ReadEpisodeTexts([id])` で題・時刻・プロット・本文を読む。本文が空なら止まり、書いて保存してから合図するよう伝える
2. **登場人物・場所を確かめる**: 登場人物・場所が結んでなければ、本文から台詞・行動のある人物と主な舞台を決めて `CastEpisode` で結ぶ(`prepare.md` の 2)。視点は頼まれたときだけ入れる。時刻(`start`)が空なら、前後の話から決めて先に入れる
3. **新しい語を足す**: 本文・プロットに出た固有の語のうち、アイデアに無いものを `AddIdeas` でまとめて足す(`turns.md` の「新しい語を足す」)
4. **確定する**: `CommitEpisode` に `id`・`main_text`(1 で読んだ本文をそのまま)を渡す。題は、作者が決めた題があればそのまま、空なら付けて渡す
5. **反映する**: `ReflectEpisode`
6. **報告する**: 下の「報告する」のとおり(本文を書いた・人物役を起こしたの項は除く)。本文と人物の設定・前の話・設定が食い違って見えた所は、直さずに報告に書く

## 報告する

終わったら書いた話の行(`episode`)を読み、次を短く報告する。本文・プロット・材料のような長いものは返答に貼らない。

- 題・時刻・視点・字数(`letters`)・足した人物・場所・足した設定の候補
- 人物役を起こした人物・手番の数・やり直した回数
- 反映の返り: 足した来歴の数、足した関係・装い・外した物・居場所の移動、入れたセリフの数、`skipped`(入らなかったもの)、差分の無い人物
