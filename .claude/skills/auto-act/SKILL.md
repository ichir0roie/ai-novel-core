「auto」(「自走」も同じ)が始める合図。人物・日数・方向づけを言われたら(「auto ノア 3」「ノアの周りを三日」「港の人たちを、疫病を気にかけて」)それに従う。

- 一回の実行は、スキル `generate-event` の単位(人物たちの一日)を一つ回すこと(`SimulateDay` を一回)。その日に動かす人物は一回でみな渡し、同じ日を何回かに分けない(分けると、先の回の目に映らなかった人物が後の回で来て、記録が食い違う)
- 対象の人物はスキル `generate-event` の「対象の人物」で決め、毎日同じ顔ぶれで回す。名指しが無ければ、本文のある最新の話の登場人物
- 日は、名指しが無ければ入口に決めさせる(人物が最後に出た日の翌日)。一日を回したら、次はその翌日を回す

- db の読み書きは自分の場所の決まり(手元は `.claude/docs/db.md`、web のセッションは `.claude/docs/web-db.md`)で行う
- コードは変えない。作品の中身はリポジトリに置かない
- 人物モードの書き込みは入口 `SimulateDay` だけで行う(書き手 `ai_append` は入口が立てる)。このスキルから別の入口で行を直さない
- 途中でユーザが止めたら、その一日が終わったところで止め、下の「終える」のまとめを返す

## 入口

| すること | 入口 | 引数 |
| --- | --- | --- |
| 人物たちの一日を動かす | `expansion.simulate_day.SimulateDay`(claude を叩く入口) | `{'character_ids': [<人物>, …](省けば本文のある最新の話の登場人物), 'date': <人物の暦の日付。省けば人物が最後に出た日の翌日>, 'nudge': <作者からの方向づけ。省いてよい>, 'parent_event_id': <作者が置いた親の出来事。省いてよい>, 'story_id': <人物を名指しせずに date を渡すとき、その日付を数える暦の作品>}` |
| 展開を読む | `expansion.read_expansion.ReadExpansion` | `{'expansion_id': …}` |
| 人物モードの展開の一覧 | `expansion.list_expansions.ListExpansions` | `{'mode': 'character', 'limit': 50}`(`actor_id` で人物に絞れる) |
| 人物の一日を取り消す | `expansion.revert_expansion.RevertExpansion` | `{'expansion_id': …}` |

- `SimulateDay` は、人物一人に会話(エージェント)を一つ持たせて一日を一つの会話で回し、一時間を二段で回す(動く段で全員を先に移し、する段で、その場所にいる人物を見て行いと次の一時間の場所を決める。場所ごとの組の中は動く順(影響力・七日の行動量)に一人ずつ、組どうしは並列)。0 時から暦の一日の時間の数だけ進める。人物の目には台詞でなく行いの粒で決めさせる。その日に始まる作者の話・出来事の時間は予定で埋め、眠る時間(起きる・寝る時刻は欲の段と前の日の眠りの不足から計算)と疲れて休む時間(七日の行動量が行動力の上限に近いほど)は規則で埋めて、会話には聞かない。眠り・食事・触れ合いは、人物の食欲・睡眠欲・性欲の段(人物の時期ごとのパラメーター。無ければ年齢)と、前の日までの満ち足り方で決まり、七日の不足で欲を満たしたいモチベーションが動く。後の人物は先の人物のその一時間の行いを見て決め、先の人物は、後の人物に働きかけられたか、一緒にいた後の人物が場所を移るときだけ一往復応じる。その日を先に動かした人物は、行動の表のとおりの場所と行いで目の前に出て、合わせては変わらない。動かしていない人物は決まった居場所(人物の `routines`。無ければ住まいにいて昼は留守)にいて、働きかけた結果だけが記録に入る。一日の終わりに、人物ごとに強いモデルで一度だけ一日を記録する(`.docs/world-expansion.md` の「人物モード」)。一日で人物の目を何十回も呼ぶので、4 人で 4〜5 分かかる。web では `flows.run` を `run_in_background` で回す
- 動かせるのは、詳細の場所(詳細マップの場所)にいる人物だけ。詳細の場所にいない人物・その日をもう動かした人物は `failed` に返る。このスキルで居場所を直す・縛りを外す回り道をしない(人物を詳細の場所へ移すのは作者に頼む)
- 返りは `date`(動かした日)・`acted`(動かせた人物の一日)・`failed`(動かせなかった人物。`error` にわけ)。`acted` の人物ごとに `expansion_id`・`character_id`・`name`・`event`(一日の出来事)・`actions`(足した一時間ごとの行動の数)・`met_ids`(居合わせて応じ合った相手)・`characters`(現れた人物)・`moves`・`motivations`(足したモチベーションの行)・`idea_ids`・`frame`(影響の枠)を読む。長いので、スクラッチパッドに書き出して `jq` で要る所だけを抜く
- 一時間ごとの行動は、表の API で読めない行動の表(`event_action`)にある。人物の一日の流れは、展開(`ReadExpansion`)の `prompt` で読む
- ミームは抜き出さない(ミームは話の本文の確定のあとにだけ抜き出す)

## 使用量を読む

止めどころは、スキル `auto-revision` の「使用量を読む」と同じに読む(このセッションの id を `get_session` で得て、`list_events` の `rate_limit_event` から 5 時間・週の使用率を読む)。読めなかったら(ツールが無いなど)、使用率による止めどころは使わずに回し、読めなかったことを `progress.md` と報告に書く。そのとき日数を頼まれていなければ、一日回したところで止める。

## 流れ

始めに、スクラッチパッドに `auto-act/progress.md` を作り、始めの使用率(読めたときだけ)と、頼まれた人物・日数・方向づけを書く。一日を終えるたびに、動かした日と、人物ごとに展開の id・出来事の名前・居合わせた相手を、終えたときの 5 時間の使用率を足す。

1. **止めるか決める**: 次のどれかに当たれば下の「終える」へ
   - 頼まれた日数を回し終えた。使用率が読めず、日数も頼まれていなければ、一日回した
   - 使用率が読めたときは、スキル `auto-revision` の「流れ」の 1 の、使用率による止めどころ(5 時間が 0.95 以上、次の一日で 1 を越える、区切りが明けた、週が 0.95 以上、追加の料金で回っている)
   - 対象の人物が全員、続けて失敗した(詳細の場所にいない・居場所が分からないなど)
2. **動かす**: 対象の人物の id を `character_ids` に、日付を決めていれば `date` に(二日目からは前に動かした `date` の翌日)、方向づけがあれば `nudge` を渡して `SimulateDay` を呼ぶ
   - `failed` の人物は、展開が `failed` で残る(展開を立てる前に止まった人物は `expansion_id` が空)。わけを `progress.md` に書き、次の日へ進む
3. **返す**: `progress.md` に足し、返答には動かした日を頭に、人物ごとに一行ずつ書く(`<人物> <日付>: <出来事>(居合わせた相手: <相手>。行動 <数> 件)`)。長い報告は「終える」でまとめる。1 へ戻る

## 終える

`progress.md` から次をまとめて返す(出来事の本文・材料のような長いものは貼らない)。

- 止めた理由と、始めと終わりの 5 時間・週の使用率(読めなかったら、そう書く)
- 日ごと・人物ごとに: 展開の id・出来事・居合わせた相手・現れた人物・住まいの移動・思いの増減
- 動きは画面の見取り図(`/overview`)で章ごとに見られる、と一行添える
- 失敗した人物とそのわけ
- 取り消すなら「展開 <id> を取り消して」(人物の一日ずつ)、と一行添える
