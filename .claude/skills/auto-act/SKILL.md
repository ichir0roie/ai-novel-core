「auto」(「自走」も同じ)が始める合図。人物・手数・方向づけを言われたら(「auto ノア 3」「ノアを三手」「港の人たちを、疫病を気にかけて」)それに従う。

- 一回の実行は、スキル `generate-event` の単位(人物一人の、一回の出来事の生成)を人物モードで一つ回すこと(`ActCharacter` に `act_count: 1`)
- 対象の人物はスキル `generate-event` の「対象の人物」で決める。名指しが無ければ、本文のある最新の話の登場人物を id の順に一人ずつ回し、一巡したら頭に戻る。名指しがあれば、その人物を先に、その人物が登場した最新の話の登場人物を続けて回す

- db の読み書きは自分の場所の決まり(手元は `.claude/docs/db.md`、web のセッションは `.claude/docs/web-db.md`)で行う
- コードは変えない。作品の中身はリポジトリに置かない
- 人物モードの書き込みは入口 `ActCharacter` だけで行う(書き手 `ai_append` は入口が立てる)。このスキルから別の入口で行を直さない
- 途中でユーザが止めたら、その一手が終わったところで止め、下の「終える」のまとめを返す

## 入口

| すること | 入口 | 引数 |
| --- | --- | --- |
| 何手か動かす | `expansion.act_character.ActCharacter`(claude を叩く入口) | `{'character_id': <一手目の人物。省けば入口が最新の話の登場人物から引く>, 'time': <省けば登場した最新の話(か、その後に AI が足した出来事)から日を空け、気力が戻るまで待たせる>, 'nudge': <作者からの方向づけ。省いてよい>, 'act_count': <この実行で回す手の数。このスキルでは 1>, 'story_id': <人物を名指しせずに time を渡すとき、その時刻を数える暦の作品>}` |
| 展開を読む | `expansion.read_expansion.ReadExpansion` | `{'expansion_id': …}` |
| 人物モードの展開の一覧 | `expansion.list_expansions.ListExpansions` | `{'mode': 'character', 'limit': 50}`(`actor_id` で人物に絞れる) |
| 一手を取り消す | `expansion.revert_expansion.RevertExpansion` | `{'expansion_id': …}` |

- `ActCharacter` は一回の実行で、手ごとに人物の一手と巻きこんだ相手との対話を一番安いモデルで順に回し、最後に実行の手をまとめて強いモデルで一度だけ裁く。一手の前後に、動く人物か居合わせる人物が出るプロットつきの話があれば、一手の前に語り部が入り、そのプロットを動機にして人物の外の状況(語り)と人物への要求を整え、裁く段にプロットと動機を渡してプロットに逆らう記録にさせない(`.docs/world-expansion.md` の「人物モード」)。プロットを人物モードに守らせたい話は、先に時刻と登場人物(かプロットに人物の名前)を入れておく。現れる人物がいれば人物の生成も回すので、数分〜十数分かかる。web では `flows.run` を `run_in_background` で回す
- 動ける人物・巻きこめる相手・裁いた結果の幅は、気力・手数・影響の枠で入口が縛る(`.docs/world-expansion.md` の「リソース制限」)。このスキルで縛りを外す・回り道をしない
- 返りは `acted`(打てた手)と `failed`(打てなかった手。`error` にわけ)。`acted` の手ごとに `expansion_id`・`actor`(人物・時刻・場所・気力・影響力)・`intent`(内心・狙い・沿ったモチベーション・行動・言葉)・`invited_ids` と `dialogue`(巻きこんだ相手と手番)・`roll`(サイコロの成り行き)・`frame`(影響の枠)・`event`・`arc_id`(企て)・`characters`(現れた人物)・`moves`・`motivations`(足したモチベーションの行)・`narration`(語り部が入った手だけ。動機にした話 `episodes`・動機 `motivation`・語り `narration`・要求 `request`)を読む。長いので、スクラッチパッドに書き出して `jq` で要る所だけを抜く
- ミームは抜き出さない(ミームは話の本文の確定のあとにだけ抜き出す)

## 使用量を読む

止めどころは、スキル `auto-revision` の「使用量を読む」と同じに読む(このセッションの id を `get_session` で得て、`list_events` の `rate_limit_event` から 5 時間・週の使用率を読む)。読めなかったら(ツールが無いなど)、使用率による止めどころは使わずに回し、読めなかったことを `progress.md` と報告に書く。そのとき回数を頼まれていなければ、対象の人物を一巡したところで止める。

## 流れ

始めに、スクラッチパッドに `auto-act/progress.md` を作り、始めの使用率(読めたときだけ)と、頼まれた人物・手数・方向づけ、回す人物の順を書く。実行を終えるたびに、打てた手ごとに展開の id・人物・時刻・巻きこんだ相手・出来事の名前を、実行ごとに終えたときの 5 時間の使用率を足す。

1. **止めるか決める**: 次のどれかに当たれば下の「終える」へ
   - 頼まれた手数を回し終えた。使用率が読めず、手数も頼まれていなければ、対象の人物を一巡した
   - 使用率が読めたときは、スキル `auto-revision` の「流れ」の 1 の、使用率による止めどころ(5 時間が 0.95 以上、次の一手で 1 を越える、区切りが明けた、週が 0.95 以上、追加の料金で回っている)
   - 対象の人物が全員、続けて失敗した(動ける人物がいない・居場所が分からないなど)
2. **動かす**: 回す順の次の人物の id を `character_id` に、方向づけがあれば `nudge` を、`act_count` に 1 を渡して `ActCharacter` を呼ぶ
   - `failed` の手は、展開が `failed` で残る(展開を立てる前に止まった手は `expansion_id` が空)。わけを `progress.md` に書き、次へ進む
3. **返す**: `progress.md` に足し、返答には打てた手を一行ずつ書く(`<人物> <時刻>: <狙い>(巻きこみ: <相手>) → <出来事>(<成り行き>)`。語り部が入った手は `[語り部: ep<id>]` を添える)。長い報告は「終える」でまとめる。1 へ戻る

## 終える

`progress.md` から次をまとめて返す(出来事の本文・材料のような長いものは貼らない)。

- 止めた理由と、始めと終わりの 5 時間・週の使用率(読めなかったら、そう書く)
- 一手ごとに: 展開の id・人物・時刻・狙い・巻きこんだ相手・成り行き・出来事・企て(続けた/始めた/閉じた)・現れた人物・居場所の移動・語り部が動機にした話(入った手だけ)
- 動きは画面の見取り図(`/overview`)で章ごとに見られる、と一行添える
- 失敗した一手とそのわけ
- 取り消すなら「展開 <id> を取り消して」、と一行添える
