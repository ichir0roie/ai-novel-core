---
name: interactive-episode
description: 作者(ユーザ)・語り部(このセッションの Claude)・人物役の順に一巡しながら、話(episode)の本文を代わる代わる書き進める(インタラクティブモード)。作者が GUI で本文を書いて保存する(かチャットで場面・指示を出す)たびに、語り部がその先を予測して場面を組み、人物役(character-actor)に手番を回し、返った一手を本文に書き足していく。一巡したら作者に番を返す。終わりの合図で手番を終え、書けた本文を世界に反映する。「ep61 in」(61 は話の id)、「インタラクティブで書きたい」「書きながら人物を動かしたい」「自分の書いた続きを人物に演じさせたい」などの依頼で使う。
---

入口・呼び方は、スキル `episode` の「入口」のとおり。
「ep<話id> in」がこのスキルを始める合図(Claude が手番を最後まで自動で回して本文を書くのは「ep<話id>」で、スキル `episode`)。

## 役と流れ

| 役 | だれ | すること |
| --- | --- | --- |
| 作者 | ユーザ | GUI の話のセッションの画面(`/episode_session?episode=<id>`)で本文を書いて保存する(Ctrl+S)。書かずに Continue で番を返す・チャットで場面や指示を出すこともある |
| 語り部 | このセッションの Claude | 作者の書いたことを読んで先を予測し、場面を組んで人物役に手番を回し、返った一手を本文に書き足す |
| 人物役 | エージェント `character-actor`(登場人物ごと) | 語り部の要求に、その人物の一手を返す |

作者が書く → 語り部が場面を組む → 人物役が動く → 語り部が本文に書き足す、を手番の着地まで繰り返し、一巡したら作者に番を返す。
番の受け渡しは話のセッションの表(`episode_character_session`)の作者の行でする。語り部が `hand-over` で作者の行を足すと作者の番になり、作者が保存する(か Continue・チャットの発言)と、その行に作者の書いたこと(前の本文からの差分か発言)が入って語り部の番に戻る。

- 作者の番のあいだ、語り部は本文に書き足せず、置き換えもできない(`append`・`replace` が断られる)。語り部の番のあいだ、画面の本文の欄は読むだけになり、語り部の書き足しを読み直し続ける
- 作者の書いた中身(起きたこと・人物の言動・台詞の言うこと)は正。語り部は中身を変えない・消さない
- 作者の文がプロットのような書き方(箇条・あらすじ・「〜する」と段取りだけを並べた文)なら、語り部がその箇所を本文の文に起こし直して置き換える(下の「作者の書き方を起こし直す」)。それ以外の作者の文には手を入れず、語り部が書き足すのは本文の終わりにだけ
- 作者の書いた人物の言動・内心は、その人物が既にしたこととして扱う。人物役に、した・言ったことを言い直させない
- 人物が場面でどう動くかは人物役が決める。語り部は人物役の一手を書き換えない(言い回しを本文の文体に起こすだけ)
- 端役(屋台の主・通行人など)と群衆は人物役を起こさず、語り部が語りと本文に書く。名前を付けず、役割か見た目で書く(スキル `episode` の「登場人物・場所」)

## コマンド

スキル `episode` の「語り部の決まり」の表(`stage`・`appearance`・`add`・`add-ideas`・`read`・`clear`)に加えて、次を使う。いずれも `.venv/bin/python -m tool.episode_session <コマンド>`。

| すること | コマンド |
| --- | --- |
| 今の本文の全文を読む | `text --episode <id>` |
| 本文の終わりに書き足す | 書き足す文を Write でスクラッチパッドのファイルに書き、`append --episode <id> --file <ファイル>`。空行を置くなら文の頭に空行を書く |
| 本文の一か所を置き換える | `{"old": <置き換える文>, "new": <置き換えた文>}` を Write でスクラッチパッドのファイルに書き、`replace --episode <id> --edit <ファイル>`。`old` は本文にちょうど一度だけ出る長さで切る。作者の行は足さない |
| 作者に番を渡す | `hand-over --episode <id> --note '<作者への一言>'` |
| 作者が書くのを待つ | `wait-author --episode <id>`(下の「作者を待つ」) |
| 作者のチャットの発言を作者の行に入れる | 発言を Write でスクラッチパッドのファイルに書き、`author --episode <id> --file <ファイル>` |

## 1. 整える

1. **登場人物・場所・関係を整える**: スキル `episode` の「セッションの前に整える」の 1〜5。プロットか登場人物のどちらかが要る(どちらも無ければ始めず尋ねる)。すでに結んである話でも飛ばさない
2. **語り部の材料を読む**: `stage --episode <id>` で場面の材料(プロット・場所・登場人物の表層・知り合いの組)を読む。本文を書き足すので、本文の材料(スキル `episode` の手順 7 の `ReadEpisodeBrief`)も読み、スクラッチパッドのファイルに書き出しておく(書き方・文体の見本・視点・前の話はここから取る。読み直すと要約の確かめが走り直すので、セッションの間はこのファイルを使う)
3. **今の本文を読む**: `text --episode <id>`。本文があれば、作者はその続きから書く

## 2. 始める

1. **前の行を見る**: `read --episode <id>` が空でなければ、ユーザに「消して始めるか」を尋ねる。消すなら `clear --episode <id>`(前の行が残ると、前の場面の語りと一手が人物役に届き、作者の番も前のセッションの続きになる)
2. **人物役を起こす**: 台詞・行動のある登場人物ごとに、エージェント `character-actor` を一つ裏で(`run_in_background`)起こす。最初のメッセージには話の id・人物の id だけを書く。人物役は起きたときに `knowledge` を読むので、1 を整え終えてから起こす
3. **作者に番を渡す**: `hand-over --episode <id> --note '<一言>'`。一言は、本文が空なら書き始める場面(プロットの最初の場面があればそれ)、本文があれば「続きをどうぞ」のように、作者が次に書くこと
4. **ユーザに返す**: 時刻・場所・登場人物(人物役を起こした人物)・整えたこと(「セッションの前に整える」の 6)を短く書き、次を一行ずつ添えて、作者を待つ
   - 画面は `/episode_session?episode=<id>`(話の画面の Session ボタンからも開ける)。右の欄に本文を書いて Ctrl+S で保存すると語り部の番になる
   - 書かずに語り部に続きを任せるなら Continue、チャットで場面や指示を出してもよい
   - 終えるときはチャットで「終わり」

### 作者を待つ

作者の番を渡したら、`wait-author --episode <id>` を `run_in_background` で回して返事を待つ(作者が書くあいだ、ユーザがチャットで話せるように)。

- 返った `status` が `written` なら、`record.action` が作者の書いたこと。下の「3. 一巡を回す」へ
- `timeout` なら、もう一度回す
- 待つあいだにユーザがチャットで場面・指示を出したら、上の表の `author` で作者の行に入れ、それを作者の書いたことにして「3. 一巡を回す」へ進む(裏の `wait-author` も `written` で返るが、同じ行なので読み捨てる)

## 3. 一巡を回す

### 読む

- 画面で保存したときの `action` は、前に保存した本文からの差分(unified diff)。`+` の行が作者の足した文、`-` の行が消した文、頭に空白の行は前後の文、`@@` の行は場所。前後だけで場面が分からなければ `text` で全文を読む
- Continue のときは「書き足さずに、続きを語り部に任せる」の一文が入る。今の本文の終わりから、作者の狙いを予測して進める
- チャットの発言はそのまま入る。場面・出来事なら作者が書いたことと同じく扱い、進め方の指示(「ノアはもっと怒る方向で」)なら要求と着地点に効かせる

### 予測する

作者の書いたことから、次の三つを決めてから手番を足す。

1. **起きたこと**: 作者の書いた人物の言動・内心、場面・時刻・場所の移り、新しい出来事。これは事実で、動かさない
2. **作者の狙い**: その文が次に何を呼ぶか(問いかけには返事、物音には振り向き、決めたことには動き出し)。プロットがあれば、いまどの場面のどこにいて、次にどこへ向かうか
3. **一巡の着地点**: 作者の書いたことへの人物の反応と、それが起こす直後の動きまで。作者が決めるべき分かれ目(新しい出来事・人物の登場・場面の切り替え・大きな選択)の手前で止める。手番は二〜六ほどを目安にし、作者の書いていない出来事を足して先へ進めない。作者がプロットのように先の場面まで書いたなら、着地点は作者の書いた所の終わり(そこまでは作者の決めたこと)

- 作者が前の文(語り部の書き足した文を含む)を直した・消した: 言い回しだけなら気にしない。起きたことが変わったなら、関わる人物の次の `request` に「さっきの〜は〜だった」と伝える。人物役の演じた手番と大きく食い違うなら、スキル `episode` の「やり直す」の 1・4・5 で、その手番から消して起こし直す
- 作者の文に、材料に無い固有の語が出たら `add-ideas` で足す(スキル `episode` の「新しい語を足す」)
- 作者の文に、新しい人物が台詞・行動を持って出たら、`CastEpisode` で登場人物に足し(まるごと置き換わるので今の人物も渡す)、その人物について「セッションの前に整える」の 3・4 を済ませ、人物役を起こしてから手番を足す

### 手番を回す

スキル `episode` の「語り部の決まり」「手番の要求を足す」のとおり、手番の JSON をファイルに書いて `add --episode <id> --turns <ファイル>` で足し、人物役に番を送る(同時に動く組は一度に)。一手は本文に起こすので、「終わった」に添えられた行動・セリフでなく、`moves` で内心まで読む。表を見張って待つのは、作者の番(下の「作者を待つ」)の語り部だけ。人物役は見張らない。このスキルで違うのは次だけ。

- 作者の書いた人物の言動は、その場の人物みなに見える・聞こえるなら語り(`narration`)に三人称で書く(本人も `witness_ids` に入れる。本人には自分のしたこととして届く)
- 作者の書いた人物の内心は、その人物の `request` にだけ書く(「あなたは〜と思った」)。ほかの人物には届けない
- 作者の書いた場面・端役の動き・時間の移り(`time` を新しい時刻にする)は語りに書く
- 作者が台詞まで決めて書いたやり取りは、語りに三人称で順に書いて渡し、言った本人の `request` に「語りにある、あなたの言葉はもう言ったこと」と添える。人物役には、そのあいだの仕草・胸のうちと、やり取りを受けた反応だけを求める
- 作者の書いた台詞・出来事が、人物役の演じた手番と食い違えば(作者が台詞を書き換えたなど)、関わる人物の次の `request` に「さっきの〜は〜だった」と伝える
- 着地点までの手番を回したら、返った一手を読んで次を足すことを繰り返す。途中でユーザに見せたり尋ねたりしない

### 本文に書き足す

人物役から「終わった」が返って一手を読むたびに、その分を本文に起こして `append` で書き足す(作者の画面では、本文がそのつど伸びていく)。

- スキル `episode` の「本文に起こす」「書くとき」と、1-2 で書き出した材料の「書き方」に沿う。作者の文の文体・視点・人称・語の選び方に合わせ、作者の文の直後から続く文にする
- 作者がもう書いた言動を、言い直して繰り返さない。作者の文が途中で切れていれば(セリフの前で止まっているなど)、その続きから書く
- 視点の決まった話では、視点人物以外の内心は書かない(行動・セリフと、視点人物から見えることだけ)
- 一度に書き足すのは、返った一手の分だけ。着地点より先を書かない

### 作者の書き方を起こし直す

作者の文がプロットのような書き方なら、その箇所を、一巡の手番の一手と合わせて本文の文に起こし、`replace` で作者の箇所と置き換える。

- 置き換えるのは語り部の番のうち(`hand-over` の前)。作者の番には断られる
- 作者の箇所が本文の終わりにあれば、起こした文は作者の箇所の後ろに `append` せず、`replace` の `new` にする。作者の箇所の後ろにもう語り部の書き足しがあり、作者の箇所の中身をそこへ起こしてあるなら、`new` を空にして消す
- 作者の書いた台詞は、言うことを変えずに入れる。誤字と書き方の決まり(セリフの終わりの「。」など)は、起こし直すときに直してよい
- 作者が、語り部の起こし直した箇所を自分で書き直した・元に戻したら、作者の版を正とし、もう一度起こし直さない
- チャットには、起こし直した箇所を一行書く

### 作者に渡す

着地点まで書き足したら、`hand-over --episode <id> --note '<作者への一言>'` で作者に番を返し、「作者を待つ」に戻る。

- 一言は、作者が次に決めること・書くこと(「隊商は丘の上で止まった。だれが先に降りるか」)を一文で
- チャットには、一巡で起きたことを一〜三行と、足した手番の数・プロットから外れた所(あれば)だけを書く。書き足した本文は貼らない(画面にある)

### 語り部の番に作者が口を挟んだら

語り部の番のあいだにユーザがチャットで場面・指示を出したら、「コマンド」の表の `author` で作者の行を挟み(手番は止めない)、まだ足していない手番と着地点に効かせる。「まて」「ストップ」なら、それ以上手番を足さず、書き足し終えた所で作者に番を返す。

## 4. 終える

ユーザが終わりを告げたら(「終わり」「ここまで」など)、手番を終えて本文を反映し、セッションの行を消す。

1. **手番を終える**: 人物役にはもう番を送らない。裏の `wait-author` は `TaskStop` で止める
2. **プロットが空なら書く**: セッションの行と本文から、`ai/instructions/plot.py` の `PLOT_FORMAT_INSTRUCTION` の形(場面ごとの見出し `# <場所と時間>` と地の文・台詞だけ)でプロットを書き、`CommitEpisode` に `id`・`plot_text` を渡して入れる
3. **本文を反映する**: スキル `episode` の「ユーザが書いた本文を反映する」の 2〜7 のとおり。本文は作者と語り部が書いたままにし、ここでは直さない
   - 「反映はあとで」と言われたら 1・2 までにし、反映は「ep<id> 書いた」であることを一行添えて終える
   - 本文を通して整えたいと言われたら、スキル `revise-episode` に移る
4. **セッションの行を消す**: 報告に使う作者の行と手番の行の数を `read` で数えてから、`clear --episode <id>`。作者の行が残ると、画面は作者と書いている最中のままになり、語り部の番の本文の欄が読むだけで止まる。反映をあとにするときも、`revise-episode` に移るときも消す(「ep<id> 書いた」は、セッションの行が無ければ本文から読む)

## 報告する

スキル `episode` の「報告する」のとおり。手番の数は、作者の番の数(作者の行の数)と、足した手番の行の数を書く。
