`CLAUDE.md` のルールに従う。入口・呼び方・本文の書き方は、スキル `episode` の「入口」「本文に起こす」「書くとき」のとおり。
スキル `episode` の手順 6(手番を回す)を、Claude が語り部として自動で回す代わりに、ユーザが語り部を務めて場面と行動を出して回すもの。
「ep<話id> in」がこのスキルを始める合図(Claude が手番を自動で回して、終えたらまとめを報告するのは「ep<話id>」で、スキル `episode`)。

- 語り部はユーザ。このセッションの Claude は、ユーザの出した場面と行動を手番の行(要求)に起こし、返った一手を見せるだけにする。場面を自分で先へ進めない・ユーザの出していない出来事を足さない
- ユーザの場面・行動に、プロットにも材料にも無い固有の語(獣・道具・店・制度・呼び名など)が出たら、手番の行を足すときに `add-ideas` でアイデアに足す(書き方はスキル `episode` の「新しい語を足す」)
- 人物が場面でどう動くかは人物役が決める。Claude は人物役の一手を書き換えない

## 前提

- 話にプロット(`plot_text`)があるか、登場人物と場所が結んであること。どちらも無ければ始めず、プロットか登場人物・場所を尋ねる
- 時刻(`start`)が空なら、前後の話から決めて先に入れる(スキル `episode` の手順 1)

## 1. 整える(Claude がする)

1. **話と人物を読む**: スキル `episode` の手順 2 のとおり、`ReadEpisodeCasting(episode_id)` で話・登場人物・候補を読み、登場人物が関わった話を読む
2. **登場人物・場所を結ぶ**
   - プロットがあれば、スキル `episode` の手順 4 で、台詞・行動のある人物と主な舞台を決めて `CastEpisode` で結ぶ(すでに結んであれば、足りない人物・場所だけ足す)
   - プロットが無ければ、結んである登場人物・場所をそのまま使う
3. **設定(アイデア)と照らす(任意)**: 設定は話に結ばず、本文の材料を読むときに、プロット・話のセッションの行に出た語で引かれる。プロットが世界の設定と食い違っていないかを先に確かめたいときだけ、スキル `episode` の手順 5 で `ResolveIdeas` に照らす
4. **関係を整える**: 登場人物ごとに `character.list_character_relations.ListCharacterRelations(character_id)` で関係を読む
   - 関係(`character_relation`)の無い二人は、人物役には初対面として渡る。前の話・プロットからすでに知り合いのはずの二人に関係が無ければ、`CommitCharacterRelation` で足す(`start` は知り合った時刻。話の時刻より後にしない)
   - 間柄が前の話と食い違っていれば、`UpdateCharacterRelation` で直す(`text` は時期を限らない芯だけ、起きたことは出来事ごとの `histories`(`start` は起きた時刻)。`data_access_logic/readme.md` の「関係の芯と来歴」)
   - 芯(`text`)に、関係のある人物も知らないはずの秘密があれば、来歴(知る相手を絞った行)へ移すようユーザに伝える
   - `.venv/bin/python -m tool.episode_session knower-gaps --episode <id>` で、来歴の知る相手の抜けを見る。返った行は、スキル `episode` の「知る相手の抜けを埋める」のとおり、一覧にしてユーザに確かめてから足す
5. **語り部の材料を読む**: `.venv/bin/python -m tool.episode_session stage --episode <episode>`。中身はプロット・場所・登場人物の表層(名前・年齢・性別・外見)・知り合いの組だけ。人物の内側と、だれが何を知っているかは人物役が自分のデータから出すので、ここには無い
6. **ユーザに返す**: 時刻・場所・登場人物(人物役を起こす人物)・足した設定の候補(3 で照らしたとき)・足した/直した関係・プロットの場面(あれば)を短く返し、最初の場面を待つ。直す指示があれば 2〜5 をやり直す

## 2. 人物役を起こす

最初の場面を受けたら(整えた中身を直す指示でなければ)、人物役を起こしてから手番を足す。人物役は起きたときに `knowledge` を読むので、関係・設定を整え終えてから起こす。

0. **前の行を見る**: `read --episode <id>` が空でなければ、ユーザに「消して始めるか」を尋ねる。消すなら `clear --episode <id>`。最後が終了の行のまま続けると、人物役がすぐ止まる
1. 台詞・行動のある登場人物ごとに、エージェント `character-actor` を一つ裏で(`run_in_background`)起こす。最初のメッセージには話の id・人物の id だけを書く
2. 端役(屋台の主・通行人など)と群衆は人物役を起こさない。ユーザの出した言葉どおりに、語りへ書く
3. 人物役が「終わった」と返して止まったのに、まだ手番を閉じていなければ、同じメッセージでもう一度起こす(`knowledge` を読み直して番を待つ)

## 3. 手番を回す(ユーザの場面ごと)

ユーザのメッセージ一つを、場面と行動の指示として受け、次を繰り返す。

1. **対象の人物を決める**: ユーザが名指しした人物。名指しが無ければ、出された行動を向けられた人物。決めかねるときは足す前に尋ねる
2. **要求を足して待つ**: スキル `episode` の「語り部の決まり」「手番の要求を足す」に沿って語りと要求を書き、`add --episode <id> --turns - --wait` で足す(Bash の timeout は 3600000)
   - ユーザの出した場面・端役の動きは、その場の人物みなに見える・聞こえるなら語り(`narration`)に一度だけ書き、`witness_ids` にその場の人物を入れる。一人にだけ分かることは、その人物の `request` に書く
   - 直前に動いた人物の行動とセリフは、`witness_ids` に入れた人物にそのまま届くので書き写さない(結果だけを語りに書く)。内心・狙いは届かない
   - `request` には、この手番で求めることを書く
   - ユーザが登場人物の行動を指示したら(「A が戸を開ける」)、その人物への「この手番で求めること」に書く(「戸を開けるところまで」)。内心・セリフは人物役に任せる
   - その人物の知らない人物像・来歴・設定の履歴は書かない。場面で明かされたときだけ書く
   - 初対面の相手は `witness_ids` に入れられない(一手が名前付きで届くので断られる)。その一手は、`appearance` で読んだ見た目で語りか要求に書く。名前は名乗る・聞くなどで分かったときだけ入れる
   - 対象の人物が複数なら、一度にまとめて足してよい。前の人物の一手は次の人物に届くので、二人目からは「<前の人物>の一手を受けて」の一手を求める(皆に同じ問いを並べると、皆が同じことを言う)。前の人物の一手の結果を語る要求は、その一手が返ってから足す
   - `time` は手番の作中の時刻(材料の「この話」と同じ形)。ユーザが時間を進めた・移動させたら、新しい時刻にし、そのあいだのことを語りにまとめる
   - 場面の途中で新しい人物が台詞・行動を持つことになったら、`CastEpisode` で登場人物に足し(まるごと置き換わるので今の人物も渡す)、人物役を起こしてから要求を足す
3. **見せて待つ**: 返った一手(`answers`)を、人物ごとに次の形で見せ、ユーザの次の指示を待つ(時刻は足したときの `time`)。次の手番を自分から足さない

   ```
   **<人物名>**(<時刻>)
   - 内心: …
   - 行動: …
   - セリフ: 「…」
   - 狙い: …
   ```

   - プロットがあり、一手が大筋から外れそうなら、見せるときに一行添える(直すかはユーザが決める。プロットは直さない)

## 4. 終える(終わりの合図)

ユーザが終わりを告げたら(「終わり」「ここまで」「本文にして」など)、手番を閉じて本文へ進む。

1. **閉じる**: `close --episode <id>` で終了の行を足す。人物役はそれを読んで止まる。止まった知らせが来ない人物役は `TaskStop` で止める
2. **プロットが空なら書く**: セッションの行から、`data_access_logic/readme.md` の「補足:」の行の下にある `## 場面` / `## 狙い` の形でプロットを書き、`CommitEpisode` に `id`・`plot_text` を渡して入れる(プロットに名前の出る人物が拾われる)。場面で固有の語が出ていれば、スキル `episode` の手順 5 で結ぶ
3. **本文を書いて確定する**: スキル `episode` の手順 7〜10 と「話のあとに、知ったことを足す」のとおり。筋はセッションの行だけから取る(「本文に起こす」)

## 報告する

スキル `episode` の「報告する」のとおり。手番の数は、ユーザが出した場面の数と、足した手番の行の数を書く。
