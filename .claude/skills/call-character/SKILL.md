---
name: call-character
description: 登場人物を一人呼び出し、その人物が出た一番新しい話(本文のある話)を終えた時点の人物として、ユーザと直に話させる(対話モード)。「17歳のネフェリアを呼んで」のように歳を言えば、本文の無いプロットの段階でも、その歳の時点の人物として呼ぶ。人物役(character-chat)を起こし、ユーザの言葉を渡して返事を見せることを繰り返す。db には書かない。「イルウェンを呼んで」「ノアを呼んできて」「〇〇と話したい」などの依頼で使う。話の手番として人物を動かすのはスキル `interactive-episode`。
---

`CLAUDE.md` のルールに従う。読み方は手元が `.claude/docs/db.md`、web のセッションが `.claude/docs/web-db.md`。
「<人物名>を呼んで」「<人物名>を呼んできて」がこのスキルを始める合図。「<歳>の<人物名>を呼んで」は、本文の有無を問わず、その歳の時点の人物を呼ぶ合図(下の「歳で呼ぶ」)。

- 人物の返事を決めるのは人物役(`character-chat`)。このセッションの Claude は、ユーザの言葉を渡して返事をそのまま見せるだけにする。返事を書き換えない・足さない・要約しない
- 対話のあいだ、このセッションの Claude は地の声を出さない。人物の返事のほかに、前置き・「返事を待っています」・続け方の案内・場面の区切りの一言を書かない(没入を損なう)。`SendMessage` を打ったターンは、文を書かずに終える
- db には書かない。話のセッションの表(`episode_character_session`)にも行を足さない。話・人物・関係・来歴は直さない(会話で出たことを残したいとユーザが言ったら、このモードを終えてから、スキル `story-director` などで扱う)

## 1. 人物と話を決める

1. **人物の id を引く**: 名前から引く(web は `/api/tables/character/options?q=<名>`、手元は `select id, name from character where name like '%<名>%'`)。同じ名が複数あれば、どれかを尋ねる
2. **一番新しい話を引く**: その人物が登場人物(`mentioned` でない)として結ばれ、本文のある話のうち、時刻(`start`)が一番新しいもの
   - web: `curl -sS -H "$h" "$api/api/tables/episode/records?sort=start&order=desc&limit=500" | jq -c '[.items[] | select((.character_ids | index(<人物id>)) and .letters > 0)][0] | {id, title, start, story_id}'`(`.total` が 500 を超えていれば `offset` で続きも読む)
   - 手元: `select e.id, e.title, e.start, e.story_id from episode e join episode_character ec on ec.episode_id = e.id where ec.character_id = <人物id> and not ec.mentioned and e.main_text <> '' order by e.start desc limit 1`
   - ユーザが話を名指ししたら(「ep61 のイルウェンを呼んで」)、その話を使う
   - 本文のある話が一つも無ければ始めず、そう伝え、「<歳>の<人物名>を呼んで」なら呼べると添える
3. **その話で人物の身に起きたことをまとめる**: `episode.read_episode_texts.ReadEpisodeTexts` `{"episode_ids":[<話id>]}` で概要(`summary_text`)と本文(`main_text`)を読み、その人物が見た・聞いた・したことだけを、その人物の目から数行にまとめる(ほかの人物の内心、その人物のいない場面は入れない)。時刻は書かない(人物役には暦を渡さない)
4. **話し相手を決める**: ユーザが「ノアとして」などと言っていれば、その人物(id を引く)。言っていなければ、その場に現れた名前を知らない相手とする

### 歳で呼ぶ

「<歳>の<人物名>を呼んで」のときは、上の 2・3 の代わりに次で時点を決めて整理する。本文が無くても、話の枠のプロット・来歴・関係の来歴を、その時点までに起きたこととして扱う(プロットの段階で人物を試すため)。

1. **歳の幅を出す**: 人物の生まれ(`ReadCharacter` の `start`)に歳を足した日から、一年後の前日まで
2. **時点を決める**: 幅の中の話の枠(本文の有無を問わない)のうち、その人物が登場人物として結ばれているか、プロットに名前の出るものを引き、時刻が一番新しいものの話を使う
   - web: 結ばれた話は `episode` の行の `character_ids`、名前の出る話は `curl -sS -G -H "$h" "$api/api/tables/episode/options" --data-urlencode 'q=<人物名>'`。手元: `episode_character` と `episode.plot_text like '%<人物名>%'`
   - ユーザが話や月を言っていれば(「17歳の、ep145 のネフェリア」「17歳の冬の〜」)、それに合う話を使う
   - 幅の中に話が無ければ、話を使わず、歳になった日を時刻にする(時刻で呼ぶ)
3. **その時点までの人物を整理する**: 次を、その人物の目から数行にまとめる。時刻は書かない(人物役には暦を渡さない)
   - 時点までの来歴(時刻を渡さない `ReadCharacter` の `histories` のうち、`start` が時点以前の行)と、関係の来歴(`ListCharacterRelations` の、時点に続いている関係の、時点までの行)
   - 時点までの話のうち、その人物が出る(結ばれている・プロットに名前が出る)もの: 本文があれば概要・本文、無ければプロット(`ReadEpisodeTexts` の `plot_text`)から、その人物が見た・聞いた・したことだけ。使う話はそのすぐ前の時点で終えたところまで
   - 時点より後のこと(後の来歴・後の話のプロット・筋書き `plot`)は入れない

## 2. 人物役を起こす

エージェント `character-chat` を一つ起こし、最初のメッセージに次だけを書く。返りの「支度ができた」を待つ。

```
話: <話id>(時刻で呼ぶときは「時刻: <年/月/日 時:分:秒>」)
人物: <人物id>
その話で自分の身に起きたこと:
<1 の 3 のまとめ>
話し相手: <人物名(人物id)。または「名前を知らない相手」>
場面: <ユーザが場所・状況を言っていればそれ。無ければ「その話のすぐあと、その場に話し相手が来た」>
```

- 人物役は話の時刻で `knowledge` を読む(その話の手番の行が残っていれば、その人物の一番新しい手番の時刻)。時刻で呼ぶときはその時刻で読み、話のプロットが無いので、アイデアは話し相手の言葉に出た語から引くものだけになる。来歴はその時刻までに始まった行だけが読める(年だけの古い行は、その年の 1 月 1 日から効く)
- 起こしたら、ユーザに次だけを短く返して最初の言葉を待つ(対話に入る前の、地の声を出す最後の所): 人物名・使った話(id・題。歳で呼んだときは歳と、使った話か「話なし」)・その話で人物の身に起きたことのまとめ(三行ほど)・話し相手・終え方(「おわり」)。歳で呼んで本文の無い話を使ったときは、プロットを起きたこととして読んだと一言添える。話し相手や話を替えたいと言われたら、人物役を起こし直す

## 3. 話す(ユーザの言葉ごと)

1. ユーザのメッセージを、話し相手の言葉と仕草として、そのまま人物役へ `SendMessage` で渡す(起こしたときの agentId 宛て)。地の文の指示(「少し時間が経って」「場所を変えて」)は、`[場面: …]` と頭に付けて渡す
2. 返った返事を、頭に `**<人物名>**` を付けて、そのまま見せる。返事のほかには何も書かずに、次の言葉を待つ。自分から話を進めない
   - 返事の最後の行が `[退場]` なら、人物がもう応えられなくなった(眠った・立ち去ったなど)。その行を除いて返事を見せ、4 の終わりの一行を添えて終える
3. ユーザが人物役でなくこのセッションの Claude に向けて話したら(「いまの返事は口調が違う?」など)、人物役へ渡さずに答える

## 4. 終える

ユーザが終わりを告げたら(「帰って」「おわり」「ここまで」など)か、人物役の返事が `[退場]` で終わったら、人物役へは何も送らずに終える。動いたままなら `TaskStop` で止める。
返すのは `(対話を終えました。db には何も書いていません)` の一行だけにする。
